# Sales Performance Analytics Dashboard

An interactive Excel dashboard for analyzing sales performance, profitability, customer activity, product categories, and geographic trends.

## Project Overview

This project converts raw sales records into an interactive business analytics dashboard. It uses Excel-based data preparation, analysis, PivotTables/PivotCharts, formulas, and visualizations to identify useful sales patterns.

### Objectives

- Analyze overall sales and profit performance
- Track sales and profit trends over time
- Compare sales across states and product categories
- Identify high-value customers and products
- Monitor customer count by year
- Present business insights through an interactive dashboard

## Tools & Skills

- **Microsoft Excel / WPS Office**
- PivotTables and PivotCharts
- Excel formulas and calculated metrics
- Data cleaning and preparation
- Data visualization
- Dashboard design
- Business and sales analytics

## Dashboard Components

| Dashboard Section | Purpose |
|---|---|
| Profit Gained Over Time | Compare yearly profit trends by category |
| Sales by States | Analyze geographic sales performance |
| Sales by Category | Compare product/category sales contribution |
| Monthly Sales | Identify monthly sales patterns |
| Top 5 Customers | Highlight customers contributing significant profit |
| Customer Count | Track customer activity across years |
| Interactive Filters | Filter the dashboard by year and category |

## Key Questions

1. How does profit change over time?
2. Which states generate higher sales?
3. Which categories contribute the most to sales?
4. Which customers contribute significantly to profit?
5. How does monthly sales performance vary?
6. How does customer activity change across years?

## How to Use

1. Clone the repository.
2. Open `Sales_Dashboard.xlsx` in Microsoft Excel.
3. Open the **Dashboard** sheet.
4. Use the Year and Category filters to explore the analysis.
5. Review the charts and supporting dataset in the `Data` directory.

## Project Outcome

The project demonstrates a practical Excel data-analytics workflow: preparing raw sales data, analyzing business metrics, creating interactive visualizations, and presenting insights through a dashboard.
